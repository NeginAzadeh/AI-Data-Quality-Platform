# AI Data Quality Platform

My Data Engineering portfolio project, built step by step with Python.

## Project goal

Build a data quality monitoring system that checks datasets for problems such as missing values, duplicate records, and unexpected data types. An AI agent will help explain detected issues and suggest next steps.

Later, extend the project into a cloud data pipeline that ingests data, runs quality checks, and reports results.

## Planned learning stages

1. Learn project organization and Git basics.
2. Build local data quality checks in Python.
3. Add monitoring reports and an AI agent.
4. Extend the system to a cloud data pipeline.

## Current status

This repository currently contains only project documentation and Git ignore rules. No functionality or dependencies have been added yet.
